# Lot 108 — Entrepôts rattachés aux fermes

Code préparé ; migration 108_warehouse_farm_scope.sql et recette connectée à effectuer.

- Ferme obligatoire pour tous les types d'entrepôt, même central. Une ferme peut avoir plusieurs entrepôts.
- Entrepôts anciens sans ferme conservés, signalés dans la page et le rapport SQL. Les rattacher via Modifier. Aucun choix arbitraire de ferme, aucun changement de quantité.
- Le changement de type d'entrepôt conserve la ferme. Le déplacement d'un entrepôt déjà utilisé vers une autre ferme est refusé ; utiliser les transferts.
- Prescription : choisir la ferme puis un de ses entrepôts actifs ; changer de ferme efface l'entrepôt, les serres et les quantités calculées.
- Contrôles SQL sur la prescription, toutes ses serres et la confirmation réelle. Les anciennes prescriptions incohérentes doivent être régularisées avant application.
- Stock : vérification dans l'entrepôt sélectionné uniquement, pas de cumul implicite avec un autre entrepôt de la même ferme. La planification sans stock reste autorisée.
- Les suggestions automatiques de transfert sont le prochain lot. Valorisation et coûts exclus.
