# Référentiel des cultures — FramPilot multi-culture

> Référentiel agronomique pour rendre l'application multi-culture, **adossé à une
> recherche multi-sources vérifiée** (recherche du 2026-06, vérification
> adversariale 3 votes/claim). Contexte : agriculture marocaine sous serre et
> plein champ — Souss-Massa / Agadir (légumes), Gharb-Loukkos / Larache &
> Moulay Bousselham (fruits rouges).
>
> **Niveau de fiabilité par donnée** (voir § Sources) :
> - ✅ **Vérifié** : variété/fait confirmé par source primaire/secondaire.
> - 🟡 **Indicatif** : ordre de grandeur agronomique générique, à ajuster.
> - ⛔ **À compléter** : pas de variété Maroc-spécifique vérifiable → l'exploitant
>   saisit ses variétés réelles (le référentiel fournit les **types/segments**).

## 4. Modèle de données proposé

### Table `crops` (culture)
| Champ | Type | Rôle |
|---|---|---|
| `code` | varchar | identifiant (`tomate`, `poivron`…) |
| `name` | varchar | libellé |
| `family` | varchar | famille botanique |
| `icon` / `color` | varchar | affichage |
| `cycle_days_first_harvest` | int | défaut plan de plantation |
| `harvest_duration_days` | int | étalement récolte |
| `default_unit` | varchar | kg / pièce / barquette |
| `brix_relevant` | bool | afficher/exiger Brix au tri ? |
| `default_markets` | jsonb | débouchés par défaut |
| `is_active` | bool | culture activée pour l'exploitation |

### Catalogue de suggestions de variétés (`crop_variety_catalog`)
Sert à **assister la création** : choisir une culture → l'app propose ces variétés.
Pré-rempli avec les variétés ✅ vérifiées (poivron, fraise, framboise). L'exploitant
les importe en 1 clic ou saisit les siennes.

| Champ | Type |
|---|---|
| `crop_code` | varchar |
| `name` | varchar |
| `segment` | varchar (California, grappe, filet…) |
| `breeder` | varchar (Syngenta…) |
| `traits` | text |
| `verified` | bool (✅ vérifié vs proposé) |

## 5. Sources & fiabilité

- **Poivron** : pages produit Syngenta Maroc (primaire) + FruitToday.
- **Fraise / Framboise / Myrtille** : FruitTrop/CIRAD F255 (primaire), USDA FAS,
  phytoloukkos, FreshFruitPortal, étude Al Awamia Souss-Massa.
- **Liste cultures** : Enza Zaden Maroc (primaire), Agrimaroc.
- **Brix** : Croptracker, OSU Extension, USDA AMS (génériques, **non Maroc-spécifiques**).
- **Réfuté (ne PAS semer)** : variétés haricot vert (Morgane/Belna/Cristal/Diamant),
  cultivars myrtille (Sharpblue/Misty/Biloxi…) — non confirmés.

**Caveat majeur** : les noms de variétés vérifiés couvrent **poivron + 3 fruits
rouges**. Pour les autres légumes, le référentiel fournit les **types/segments**
(fiables) mais **pas** de noms de cultivars — c'est volontaire (intégrité des
données) et l'exploitant complète selon ses semenciers réels.
